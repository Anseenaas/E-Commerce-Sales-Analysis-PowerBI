# E-Commerce Sales Analysis | Power BI

## About the Project

This project analyzes e-commerce sales data to understand overall business performance, profitability, regional performance, product performance, and customer payment preferences.

The analysis focuses on transforming raw sales data into meaningful business insights using Power BI, supported by SQL and Python for data analysis and validation.

An interactive Power BI dashboard was developed to monitor key business metrics and identify sales trends, profitable categories, high-performing regions, top sub-categories, and payment patterns. The goal is to support data-driven decision-making through clear and actionable insights.
